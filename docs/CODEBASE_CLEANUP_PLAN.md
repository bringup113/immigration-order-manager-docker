## 拆分原则

1. 页面负责布局和组合，业务状态与动作进入专用 Hook，金额、权限、审计和数据库规则继续留在共享领域层。
2. 桌面和手机共用业务逻辑，但保留各自展示组件，不为追求复用强行统一界面。
3. 每次只拆一个可验证边界；先补或保留测试，再移动代码。
4. 不新增旧版兼容入口，不修改历史迁移，不触碰现有业务数据和附件。
5. 新增、修改或删除业务动作时，同步检查服务端权限、订单范围、审计日志和回归测试。
