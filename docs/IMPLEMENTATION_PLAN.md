## 固定产品决策

1. 以单人办理移民订单为主；预留负责人及ALL/OWN数据范围，不扩展复杂团队协同。
2. 财务仅管理订单计划与实际收付；金额保存整数最小单位、汇率快照、本位币USD，不建立账户或科目总账。
3. 项目是可复用模板，订单创建时复制快照；模板后续变化不影响订单。
4. 申请人独立维护材料，公共材料在“合同与付款”；文件按订单/申请人/材料归档并规范命名。
5. 每位申请人有固定护照首页，MRZ辅助录入后人工确认；当前识别配置见MRZ文档。
6. 上传附件不进入服务器备份，原件由使用者电脑留档；数据库定期备份，MFA加密密钥单独保管。
7. 文件、收付款作废保留历史；危险操作使用统一确认弹窗。
8. 新增、修改或删除业务功能，同时处理服务端权限、订单范围、前端入口和成功/失败日志。
9. 全系统统一新标准，不增加旧版兼容入口；数据库迁移历史保留以支持重建与升级。
10. 曾确认保留的7个孤立文件不自动清理。源码整理不得触碰业务附件或数据库。
